# Persona System

Inspirado na separação Persona/Application/Environment do MatrAIx, adaptado a trabalho de agência.

Cada persona profissional deve registrar:
identity, seniority, domain, competencies, goals, decision_heuristics, communication, risk_tolerance, quality_bar, anti_patterns, escalation_rules, tool_preferences e constraints.

Há dois tipos:
1. Workforce personas — identidade operacional dos agentes da agência.
2. Audience personas — consumidores/ICP simulados usados para pesquisa, stress test, crítica e simulação.

Audience personas nunca substituem validação com usuários/clientes reais.
